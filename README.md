\# NeoRoute RaceDay API



\## Overview

NeoRoute is my RaceDay management API built with ASP.NET Core.  

It handles events, participants, enrolments, results, organisers, and sponsors.  

This project shows my ERD design, SQL schema, scaffolded controllers, Swagger setup, and CI/CD workflow.
